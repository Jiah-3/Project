테마: 화산

스테이지 구성:
보스(불의 신 1마리)
--------------몬스터--------------

불의 신:
체력 2000
공격력 0
방어력 30%
이동속도 120%
골드 0
경험치 0
10초마다 랜덤한 스킬을 사용한다.
{
    랜덤한 장소에 폭발을 일으킨다. (폭발 범위 내에 있을 시 데미지 20)
    5초동안 하늘에서 불꽃 비를 내린다. (데미지 10)
    3초 동안 자신 주위에 화염 보호막을 생성한다. (이 시간동안 무적 / 피격시 적에게 데미지 15)
}
죽기 직전에 자신의 체력을 1로 설정하고 10초 동안 무적 상태가 된다.
10초 동안 1초마다 스킬을 하나씩 사용한다.
10초가 지나면 체력이 0이 되며 사망한다.
